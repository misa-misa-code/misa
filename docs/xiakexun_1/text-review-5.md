# 结局文案重写（统一到完美犯罪水平）

## 暴发户 💰
鸭腿大叔的银行账户多了好几个零。虽然棘梁山的大佛盯着他摇头，文庙的孔子像也皱起了眉头——但他不在乎。钱是实打实的。"下次？下次我还敢。"

## 亡命天涯 😰
从洪顶山逃到天池山，从3条命逃到只剩1条。鸭腿大叔的脚印遍布平阴、东平，但没有一处石刻愿意记住他。"僧安道壹刻经我逃命，他是文化人，我算什么。"说罢钻进一辆驶往隔壁县的中巴车，从此杳无音信。

## 摊子被端了 🚔
市监局在8个景点找到了足够证据。鸭腿大叔表示："鸭腿大叔是一种精神，不是一种食材。就好比果蔬汁是一种比喻，不是一种配方。"执法人员面无表情地开出了罚单。令人意外的是，8个景点的游客纷纷表示：其实味道还行，哎，可惜吧……

## 老实人 😐
没赚几个钱，但也没留什么把柄。鸭腿大叔看着微薄的收入叹了口气。旁边的种田大爷递来一根烟："小伙子，我养了二十年鸭子，要不要学学？"鸭腿大叔陷入了沉思。（亲亲，这边建议找个班上呢！）

## 还行吧 👍
赚了点小钱，丢了点证据，磕磕绊绊但总算混过去了。鸭腿大叔决定今晚加个鸭腿犒劳自己——打开冰箱，只剩一只发绿的。"果蔬汁腌的，"他对着空荡荡的厨房自言自语，"葱汁。是葱汁。"
