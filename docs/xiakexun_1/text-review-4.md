# 六种结局文案审核

## 结局1：完美犯罪 🍗
- 条件：0条命丢 + 漏证据<4个 + 赚≥¥350
- 标题：完美犯罪
- 文案：鸭腿大叔笑到了最后。他的秘诀是——永远比游客跑得快一步。但平阴和东平的每一处石刻都记住了他。僧安道壹如果在天有灵，可能会题八个字：「精跨羲诞，腿越鸭鹅」。（僧安道壹：我没说啊！）

## 结局2：暴发户 💰
- 条件：赚≥¥400 + 丢过命
- 标题：暴发户
- 文案：钱赚到了，但屁股没擦干净。好几个景点都留下了把柄，下次换个地方摆摊吧。

## 结局3：亡命天涯 😰
- 条件：赚<¥200 + 丢≥2命
- 标题：亡命天涯
- 文案：命都快没了，钱也没赚几个。鸭腿大叔捂着伤口逃出了最后一个景点，发誓再也不卖假鹅腿了。

## 结局4：摊子被端了 🚔
- 条件：漏≥4证据 + 丢过命
- 标题：摊子被端了
- 文案：市监局在8个景点找到了足够证据。鸭腿大叔表示："鸭腿大叔是一种精神，不是一种食材。就好比果蔬汁是一种比喻，不是一种配方。"

## 结局5：老实人 😐
- 条件：赚<¥150 + 漏<2证据
- 标题：老实人
- 文案：没赚几个钱，但也没留什么把柄。鸭腿大叔看着微薄的收入叹了口气：老实人真的能发财吗？（亲亲，这边建议找个班上呢！）

## 结局6：还行吧 👍
- 条件：不满足以上任何条件（默认结局）
- 标题：还行吧
- 文案：赚了点小钱，丢了点证据，磕磕绊绊但总算混过去了。鸭腿大叔决定今晚加个鸭腿犒劳自己，可惜家里只剩绿鸭腿了。摔！
